# Solar Lens HK 2.3 — original library and optional saving

Released 4 November 2026.

The library starts with the original **11 places / 22 photos**. New trials no longer appear as saved places or change pooled library totals, exports or maps.

## Save or trial

- **New study** opens a place-name dialog with **Trial only** selected by default, plus **Save to data library** as an explicit alternative.
- A trial supports photo upload, real detection, calibration, review and export. It lives only in the open workspace. Reloading or changing studies discards it. The trial banner and save status explain this.
- **Save to data library** keeps the current trial on this device and enables subsequent autosaving. Choosing Save in the starting dialog does the same after adding a photo. A saved place survives reload.
- Opening a project JSON creates a new trial copy. Restoring a library backup is an explicit save action. The optional live HAECO example opens as a trial.
- Reattaching the same original preserves existing original-place reviews. Uploading a different photo while an original place is open forks a separate trial instead of overwriting the original entry.

## Cleanup and recovery

Existing browser records from earlier releases did not record a save choice. On first loading the update, these added places move out of the active library into **Removed places**. Original-place records and their reviews are preserved. Explicitly saved v2.3 places are retained on subsequent loads.

Each added-place card has **Remove**. **Remove all added places** clears all additions from the active library. Both are recoverable through **Removed places → Restore to library**. The original 11 places have no remove action and are protected by the storage layer.

Removal moves the record from saved storage to removed storage in one IndexedDB transaction. Pending failed saves are discarded for the removed ID so retries cannot resurrect it. Removed places and trials do not enter active-library totals, all-library maps, summary exports or saved-library backups. A trial can still be exported individually.

Storage remains local to each browser and website origin. Reloading the public website applies cleanup to that browser's public-site library; the private mirror has separate storage. Removing an active saved place leaves its open workspace as a trial. The original source imagery and model assets are unchanged.

## Verification

- **43 tests pass**, including original-place identity, cleanup idempotence, preserved reviews, explicit save eligibility and preventing failed-save retries from resurrecting removed places.
- Existing local browser data migrated from 16 studies to **11 studies / 22 photos**; five old additions remained recoverable outside the library.
- A real trial scan of the supplied HAECO crop returned 38 candidate regions and 1,893.9 m²; the library remained at 11 places. Explicit saving increased it to 12 and survived reload.
- Both the starting Save choice and later Save button persisted a place. Trials were discarded on reload. Individual removal, restore, bulk removal and reload returned the active library to 11 places.
- A different photo uploaded into an original place opened as a trial; the original library stayed at 11 places.
- The new dialog fit a 390 × 844 viewport without document-level horizontal overflow. Browser checks produced no application console errors.

Panel counts remain estimates until physically counted and entered. Review and measurement limitations are unchanged.
